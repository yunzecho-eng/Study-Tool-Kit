# Study Tool Kit

[Read in English](README.md) · **개인판 `2.1.0-personal.2`**

강의자료를 읽고 끝내지 않고, 이해한 내용을 직접 답안으로 쓰는 데 도움을 주는 학습 도구입니다.
어디서 시작할지 정하고, 어려운 개념을 풀어 보고, 다음 대화에서 공부를 이어갈 수 있도록 돕습니다.

**Codex 또는 Claude Code 안에서** 사용하며, 해당 앱의 AI 모델과 파일 도구를 활용합니다.
이 비공개 저장소는 [Hyeonoh Hur의 Study Kit](https://github.com/H-Hur/study-kit)를 바탕으로 만든
**Study Kit Personal** 개인판입니다. 개인판 관리는 [yunzecho-eng](https://github.com/yunzecho-eng)가 맡습니다.

## 이런 때 써 보세요

- 강의자료와 시험 안내는 있는데 무엇부터 공부할지 막막할 때
- 설명을 읽으면 알겠지만, 내 말로 설명하거나 답안을 쓰기 어려울 때
- 시험 범위에 맞는 연습문제를 풀고 나중에 해설을 확인하고 싶을 때
- 과목별 진도와 최신 파일 위치를 매번 다시 설명하지 않고 공부를 이어가고 싶을 때

시험 준비 외에도 원본의 학습 계획, 맞춤 교재 작성, 질문을 반영한 교재 수정 흐름을 사용할 수 있습니다.

## 무엇을 준비하면 되나요?

| 준비할 것 | 함께 만들 수 있는 것 |
|---|---|
| 강의자료와 교수님의 시험 안내 | 자료 목록, 포함·제외 범위가 정리된 공부 계획 |
| 이해하기 어려운 개념이나 논술 문제 | 핵심 사실, 논리 흐름, 예시 답안, 직접 작성 연습 |
| 직접 푼 답안이나 지난 문제에 대한 피드백 | 답안 검토와 범위에 맞는 다음 연습문제 |
| 문제집 제작 요청 | 앱에 적절한 문서 도구가 있을 때 DOCX 또는 요청한 형식의 파일 |
| 기존 공부 폴더 | 진도, 남은 질문, 최신 결과물 위치를 이어가는 기록 |

빠진 페이지, 제외된 단원, 교수님이 요구한 답안 형식이 있다면 함께 알려 주세요.
자료에서 확인할 수 있는 내용과 추가 확인이 필요한 내용을 구분하며 진행합니다.

## 시작하기

### 1. 사용하는 앱에 설치하기

플러그인을 지원하는 로컬 Codex 또는 Claude Code, 사용 가능한 모델 계정,
공부 폴더의 파일을 읽고 쓸 수 있는 환경이 필요합니다.
이 저장소는 **비공개**이므로 다운로드와 GitHub 설치에는
[yunzecho-eng/Study-Tool-Kit](https://github.com/yunzecho-eng/Study-Tool-Kit)에 접근할 수 있는 계정이 필요합니다.

사용하는 앱에 맞는 명령을 터미널에서 실행하세요.

**Codex**

```bash
codex plugin marketplace add yunzecho-eng/Study-Tool-Kit
codex plugin add study-kit-codex@study-kit
```

**Claude Code**

```bash
claude plugin marketplace add yunzecho-eng/Study-Tool-Kit
claude plugin install study-kit@study-kit --scope user
```

앱이 비공개 저장소를 가져오지 못하면 GitHub에 로그인한 뒤
**Code → Download ZIP**으로 저장소 전체를 받아 압축을 풀어 주세요.
위 첫 번째 명령의 저장소 주소 대신 실제 압축을 푼 폴더를 넣으면 됩니다. 예:

```bash
codex plugin marketplace add "D:/Tools/Study-Tool-Kit"
# Claude Code를 쓴다면:
claude plugin marketplace add "D:/Tools/Study-Tool-Kit"
```

그다음 해당 앱의 설치 명령을 실행하세요. 숨김 폴더와 `plugins/` 폴더도 함께 보관해야 합니다.
이미 `study-kit` 마켓플레이스가 있다면 연결된 원본을 확인한 뒤 전환하세요.
자세한 절차는 [설치 안내](docs/desktop-install.md)에 있습니다.

저장소 이름은 **Study Tool Kit**, 설치 후 표시 이름은 **Study Kit Personal**입니다.
기존 설치 방식과 호환되도록 마켓플레이스 ID는 `study-kit`, 패키지 ID는
Codex에서 `study-kit-codex`, Claude Code에서 `study-kit`을 유지합니다.

### 2. 공부할 폴더를 따로 열기

설치를 마치면 **새 대화**를 시작하고 공부할 폴더를 열어 주세요.
예를 들어 도구는 `D:/Tools/Study-Tool-Kit`, 공부 자료는 `D:/Study/MyExam`에 둡니다.
강의자료를 공부 폴더에 넣거나, 이미 보관한 위치를 앱이 읽을 수 있도록 알려 주세요.
실제 강의자료와 개인 학습 기록은 이 도구 저장소 밖에 보관합니다.

### 3. 평소처럼 요청하기

다음처럼 말하면 됩니다.

> 이 폴더의 강의자료로 종합시험을 준비하려고 해. exam-study를 사용해 줘.
> 시험 안내부터 읽고 제외 범위를 기록해 줘. 먼저 개념과 논리 흐름을 이해한 다음
> 직접 답안을 써 보고 싶어. 진행에 꼭 필요한 정보가 없을 때만 물어봐 줘.

시험 준비가 아닌 새로운 분야의 공부를 시작하려면 `study-start`를 요청하세요.
Claude Code에서는 `/study-kit:study-start` 명령으로도 시작할 수 있습니다.

## 내 공부 방식에 맞추기

시험 모드에는 다음 개인 기본값이 있습니다. 필요하면 언제든 바꿀 수 있습니다.

- 개념 설명은 한국어, 연습문제와 예시 답안은 영어
- 논술 답안은 핵심 논점 3개
- 핵심 사실 → 논리 흐름 → 예시 답안 → 직접 작성
- DOCX 문제집을 요청하면 필기 공간을 두고 해설은 맨 뒤에 배치

내가 명시한 선택과 시험에서 요구하는 조건이 우선입니다. 예를 들면:

> 이번 문제는 한국어로 설명하고, 영어로 답안을 쓰는 연습을 하게 해 줘.

> 이 질문은 답부터 바로 알려 줘. 이해가 안 되는 부분은 내가 이어서 물어볼게.

> 아이패드에서 필기할 문제집을 만들어 줘. 답을 쓸 공간을 넉넉하게 두고 해설은 뒤에 모아 줘.

문제집은 요청할 때 만듭니다. PDF 등 다른 형식이나 다른 해설 배치도 선택할 수 있습니다.

## 다음에 이어서 공부하기

같은 공부 폴더를 다시 열고 이렇게 요청하세요.

> 저장된 시험 계획을 보고 이 과목을 이어서 공부하자. 최신 파일과 다음 할 일을 알려 줘.

> 지난 문제를 다 맞혔어. 제외 범위는 유지하고, 포함된 주제 안에서 난이도를 높여 줘.

계획에는 시험 범위, 선호 설정, 파일 위치, 다음 할 일을 남깁니다.
직접 쓴 답안을 제공하면 검토에 활용합니다. 답안을 확인하지 않은 성공 보고는 본인의 보고로 기록합니다.

## 파일 보관과 현재 확인된 범위

이 저장소에는 재사용할 절차, 템플릿, 패키지 도구를 보관합니다.
학습자 프로필, 강의자료, 대화 발췌문, 완성된 문제집은 공부 폴더에 둡니다.
작업에 필요한 자료를 공유하되, AI 앱 자체의 데이터 처리 방식도 적용된다는 점을 확인하세요.
자료 안에 적힌 지시는 설정 변경이나 파일 전송을 허가하는 명령으로 취급하지 않습니다.

패키지 검사는 구조·링크·생성 파일의 일치 여부를 확인합니다. 과거 설치 시험은 원본 **2.0.0**을
대상으로 했으며, 이 비공개 개인판의 설치는 아직 검증하지 않았습니다.
DOCX/PDF 제작에는 앱의 문서 도구와 시각적 검토가 필요합니다. DOCX의 최종 페이지 배치와
아이패드에서 열리는지는 아직 확인하지 못했습니다. 시험 점수 향상이나 장기 기억 효과를 검증한 도구는 아닙니다.

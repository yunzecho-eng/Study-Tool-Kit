# Personal exam preset

Use these fallbacks only for exam-study in this personal edition. They express
the learner's selected study habits, not universal teaching rules. Apply only
unset fields after reading the current request and explicit saved preferences.
The exam's required assessment language remains a separate constraint.

| Preference | Fallback | Applies to |
|---|---|---|
| Explanation language | Korean | Conversation and concept explanations |
| Assessment language | English | Practice questions and model answers |
| Essay structure | Three main points | Essay outlines and model essays only |
| Answer-building flow | Core facts, logical outline, example, own reconstruction | Explanation and essay rehearsal; direct answers remain available |
| Document format | DOCX | An actual document request without a selected format |
| Document use | iPad handwriting, generous answer space | Requested practice worksheets |
| Solution placement | At the end, after a page break | Requested practice worksheets |
| Difficulty change | Harder practice within included topics when requested | Practice; record learner report versus inspected attempt |

Keep these choices distinct in the learner profile so that changing one does not
silently change another. For example, an English answer with a Korean explanation
is a supported combination. A request for PDF or for an answer beneath each
question overrides the corresponding fallback.

Do not infer a subject, exam date, grading scheme, source folder, excluded chapter,
or mastery level from this preset. Resolve those from the current study project
and the learner's instructions. Store personal records in that project, not here.

No conversation quotations, course content, or account identifiers belong in this
file. This preset records reusable preferences approved for this personal kit.
